# Slack Post Skill

## Format

- **Headline**: Start with a short bold line (`*Headline*`) summarizing the update
- **Body**: 2-4 short paragraphs or a bulleted list of key points
- Use Slack mrkdwn: `*bold*`, `_italic_`, `` `code` ``, `>` quotes, and `•` or `-` bullets
- Include 1-3 relevant emojis (e.g. :rocket:, :mag:) without overdoing it
- Link sources inline as `<https://example.com|link text>`
- End with a clear ask or next step when relevant

## Tone

- Friendly, concise, and direct
- Write for skimming: lead with the takeaway
- Avoid long preambles and corporate jargon
- Use @channel/@here only when the message is truly urgent

## Length

- Ideal: 50-150 words
- Keep it short enough to read without expanding "Show more"
